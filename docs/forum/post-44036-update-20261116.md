**Update, 16 November: five more fixes offered upstream since the last post.**

**Firmware (u1-klipper), both as draft pull requests with the patch and test in this repository:**

- Mixed nozzle sizes ([#30](https://github.com/Snapmaker/u1-klipper/issues/30), PR [#31](https://github.com/Snapmaker/u1-klipper/pull/31)). With heads of different nozzle sizes, a file whose per-tool nozzle list matches the heads is refused at start with "nozzle diameter mismatch": every used head is compared with the first entry of the list. The patch compares each used tool with its own entry. The test starts the job the way Moonraker does: 3 of 7 cases fail on stock 2.1.0, all pass with the patch, 4 deliberately wrong versions fail.
- PCTG on the 0.2 nozzle (PR [#32](https://github.com/Snapmaker/u1-klipper/pull/32)). PCTG is refused on a 0.2 mm nozzle because the `PC` prefix test meant for polycarbonate blends also matches `PCTG`. Three lines changed; the test calls the firmware's own check, red on stock 2.1.0, green with the patch.

**Moonraker on the U1 (u1-moonraker), three pull requests:**

- [#11](https://github.com/Snapmaker/u1-moonraker/pull/11) (fixes #4): the shipped `moonraker.conf` trusts `192.0.0.0/8` where the private range `192.168.0.0/16` was meant.
- [#12](https://github.com/Snapmaker/u1-moonraker/pull/12) (fixes #2, open since August): a filament type with a space, such as `"PLA Matte";PLA`, was stored as `PLA Matte";PLA`. Quotes are now removed from each entry.
- [#13](https://github.com/Snapmaker/u1-moonraker/pull/13): since firmware 1.6.0, a file sliced by Cura or by any slicer outside the Orca family gets no metadata at all. Five new metadata keys only have a parser for Orca-style files, so the script stops with an error. On a Cura file: no metadata on main, metadata with the fix.

**Limits.** None of the five was run on a printer: I do not have a U1 with mixed nozzles, and the Moonraker fixes are checked on the firmware's own scripts, not on the touchscreen. I do not know how the screen shows a file without metadata. All five are waiting for review.

The README lists every fix with its evidence: https://github.com/DesignMaster-Solutions/u1-fixpack
